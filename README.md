## 🚀 How to Run Locally

```bash
# 2. Open in browser

open index.html
```

Or simply **double-click** `index.html` to open in your browser — no setup needed!

---

## 🌐 Deploy on GitHub Pages

1. Go to your repository **Settings**
2. Click **Pages** from the left menu
3. Under **Branch** select `main` → `/root`
4. Click **Save**
5. Your site will be live at:

```
https://yourusername.github.io/portfolio
```
